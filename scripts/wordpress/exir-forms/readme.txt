Embed forms created in Exir ERP (فرم‌ساز) with a shortcode.

== Description ==
Use [exir_form url="https://YOUR-PANEL/f/<key>/<slug>"] in any page or post. Optional attributes: theme (light|dark|auto), lang (fa|en), primary (#hex), redirect, success_message, min_height, hide_title.
The form is rendered in an auto-resizing iframe; submissions go straight to your Exir panel.

== Installation ==
1. Plugins > Add New > Upload Plugin, choose the zip, activate.
2. Paste the shortcode shown in Exir > Forms > "اتصال به سایت" > WordPress.

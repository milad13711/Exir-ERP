# راهنمای اتصال ایجنت هوش مصنوعی به اکسیر (MCP)

با این راهنما در حدود ۵ دقیقه ایجنت هوش مصنوعی خودتان (Claude، Cursor یا هر برنامه‌ی سازگار با MCP) را به اکسیر وصل می‌کنید. ایجنت می‌تواند وظایف، نامه‌ها، بارها، نوبت‌ها، مشتریان و موجودی را ببیند و برایتان پیشنهاد ثبت بدهد؛ **هیچ ثبت یا تغییری بدون تأیید خودتان در پنل انجام نمی‌شود.**

## گام ۱ — ماژول را فعال کنید

در پنل اکسیر ← «فروشگاه ماژول‌ها» ← ماژول **«اتصال API و MCP»** را فعال کنید. ایجنت فقط به ماژول‌هایی دسترسی دارد که خودتان نصب کرده‌اید (مثلاً بدون ماژول «مکاتبات»، ابزارهای نامه‌ها در دسترس نیست).

## گام ۲ — یک کلید با کمترین دسترسی بسازید

تنظیمات ← **API، وب‌هوک و MCP** ← «ساخت کلید جدید». سه سطح دسترسی دارید:

| سطح | ایجنت چه کاری می‌تواند بکند؟ | برای چه کسی؟ |
|---|---|---|
| **فقط‌خواندنی (پیشنهادی)** | فقط ببیند و گزارش بگیرد | شروع، گزارش‌گیری، تحلیل |
| **خواندن + ثبت درخواست‌های نیازمند تأیید** | بخواند و پیشنهاد ثبت بدهد؛ اجرا فقط پس از تأیید شما | دستیار روزمره |
| **دسترسی کامل REST** | علاوه بر موارد بالا، برنامه‌ی شما مستقیم از REST API بنویسد | فقط برنامه‌های مورداعتماد خودتان |

گزینه‌های اضافه (همه اختیاری):

- **محدود به ماژول‌های خاص:** مثلاً فقط «وظایف» و «CRM». ابزارهای ماژول‌های دیگر اصلاً به ایجنت نشان داده نمی‌شود.
- **انقضا:** ۳۰ روز، ۹۰ روز یا یک سال؛ پس از آن کلید خودکار از کار می‌افتد.
- **IP مجاز:** اگر ایجنت از یک سرور با IP ثابت کار می‌کند، فقط همان را مجاز کنید (`203.0.113.7` یا `10.0.0.0/24`).

> کلید فقط **یک‌بار** نمایش داده می‌شود (شبیه `exir_live_…`). همان لحظه کپی کنید؛ اکسیر فقط یک اثر انگشت رمزنگاری‌شده از آن نگه می‌دارد و بعداً قابل بازیابی نیست.

## گام ۳ — آدرس سرور شما

در همان صفحه، کارت «اتصال از طریق MCP» آدرس دقیق سرور شما را نشان می‌دهد و دکمه‌ی کپی دارد. شکل کلی:

```
https://<آدرس-سرور-اکسیر-شما>/api/mcp
```

احراز هویت: هدر `Authorization: Bearer exir_live_…`

## گام ۴ — تنظیمات برنامه‌ی هوش مصنوعی

کارت **«راهنمای اتصال گام‌به‌گام»** در پنل همین بلوک‌ها را با آدرس واقعی شما پر کرده و دکمه‌ی کپی دارد. به‌جای `XXXX` کلید خودتان را بگذارید.

### Claude Desktop

Settings ← Developer ← Edit Config، سپس (نیازمند Node.js):

```json
{
  "mcpServers": {
    "exir-erp": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://<آدرس-شما>/api/mcp", "--header", "Authorization:${EXIR_AUTH}"],
      "env": { "EXIR_AUTH": "Bearer exir_live_XXXXXXXXXXXXXXXXXXXXXXXX" }
    }
  }
}
```

برنامه را کامل ببندید و دوباره باز کنید.

### Cursor

فایل `~/.cursor/mcp.json` (یا Settings ← MCP):

```json
{
  "mcpServers": {
    "exir-erp": {
      "url": "https://<آدرس-شما>/api/mcp",
      "headers": { "Authorization": "Bearer exir_live_XXXXXXXXXXXXXXXXXXXXXXXX" }
    }
  }
}
```

### ChatGPT

فعلاً **پشتیبانی نمی‌شود**: ChatGPT برای اتصال به سرور MCP از ورود OAuth استفاده می‌کند و هدر ثابت Bearer نمی‌پذیرد، و اکسیر هنوز OAuth ندارد. فقط روش‌های بالا (Claude Desktop، Cursor و کلاینت‌های هدر-سفارشی) امروز کار می‌کنند.

### سایر برنامه‌ها

هر کلاینتی که MCP روی HTTP (Streamable HTTP) و هدر سفارشی را پشتیبانی کند فقط دو مقدار می‌خواهد: **آدرس سرور** و **هدر Authorization**.

## گام ۵ — امتحان کنید

نمونه‌پرسش‌های خواندنی (با کلید «فقط‌خواندنی» هم کار می‌کنند):

- «وظایف معوق را فهرست کن و بگو هرکدام پیش چه کسی است.»
- «وضعیت وظیفه‌ی TASK-000123 و خط زمانش را بگو.»
- «نامه‌های وارده‌ی بدون پاسخ این ماه را پیدا کن.»
- «کدام نامه‌ها منتظر امضا هستند؟»
- «بارهای منطقه‌ی شیراز که وزن خالصشان بیش از ۲۰ هزار کیلو است را بیاور.»
- «فردا برای خدمت «ویزیت» چه ساعت‌هایی آزاد است؟»
- «کالاهای زیر نقطه‌ی سفارش را فهرست کن.»

نمونه‌پرسش‌های نیازمند تأیید (کلید «خواندن + درخواست تأیید»):

- «یک وظیفه برای علی بساز: ارسال پیش‌فاکتور، موعد پنجشنبه، اولویت فوری.»
- «نامه‌ی وارده‌ای از شرکت X با شماره‌ی ۱۲۳ و تاریخ دیروز ثبت کن.»
- «از روی فاکتور ۱۰۴۵ بار اعلام کن.»
- «برای آقای رضایی فردا ساعت ۱۰ نوبت بگیر.»
- «سرنخ فلانی را رد صلاحیت کن؛ دلیل: بودجه ندارد.»
- «پیش‌نویس یک نامه‌ی داخلی برای مدیر مالی بنویس.»

## چه کارهایی «تأیید» می‌خواهد؟

هر کاری که چیزی را **ثبت، ویرایش یا حذف** کند. ایجنت فقط یک درخواست می‌فرستد؛ شما از «دستیار هوشمند (MCP)» در پنل (یا پنجره‌ی اعلان زنده) آن را می‌بینید و **تأیید** یا **رد** می‌کنید. فقط پس از تأیید شما اجرا می‌شود و با قواعد عادی خود اکسیر (شماره‌گذاری، دسترسی‌ها، جلوگیری از تکرار) انجام می‌شود. خودِ کلید هیچ‌وقت نمی‌تواند درخواستی را تأیید کند.

چیزهایی که ایجنت **اصلاً** ندارد: پیام‌رسان داخلی (حریم خصوصی)، نامه‌های «سری»، پیش‌نویس نامه‌های دیگران، ثبت رسید/حواله‌ی انبار.

## نکته‌های امنیتی

1. با «فقط‌خواندنی» شروع کنید؛ فقط وقتی لازم شد دسترسی را بالا ببرید.
2. برای هر ایجنت/برنامه یک کلید جدا بسازید تا بتوانید جداگانه ابطال کنید.
3. انقضا بگذارید و در صورت IP ثابت، IP مجاز را تنظیم کنید.
4. کلید را در چت، گیت، اسکرین‌شات یا ایمیل نگذارید.
5. هر چند ماه یک‌بار **چرخش** بدهید: کلید جدید با همان دسترسی‌ها ساخته می‌شود و کلید قبلی ۲۴ ساعت مهلت دارد تا جایگزین کنید.
6. در لیست کلیدها «آخرین استفاده» و IP را ببینید؛ استفاده‌ی غیرمنتظره = فوراً «ابطال».
7. کلیدهای قدیمی با برچسب «کلید قدیمی – دسترسی کامل» نشان داده می‌شوند؛ بهتر است با کلید محدودتر جایگزینشان کنید.

## عیب‌یابی

| پیام / کد | معنی | راه‌حل |
|---|---|---|
| **۴۰۱** — «کلید API نامعتبر یا غیرفعال است» | کلید اشتباه، باطل، منقضی، یا درخواست از IP غیرمجاز (عمداً علت دقیق گفته نمی‌شود) | کلید را دوباره بررسی کنید؛ در لیست کلیدها وضعیت/انقضا/IP را ببینید؛ در صورت نیاز کلید جدید بسازید |
| **۴۰۳** — «این کلید … فقط‌خواندنی است» / «اجازه‌ی استفاده از این ابزار را ندارد» | سطح یا ماژول‌های کلید کافی نیست | کلیدی با سطح مناسب (یا ماژول لازم) بسازید |
| **۴۰۳** — «دسترسی به MCP فقط برای مالک یا مدیر است» | کلید باید توسط مالک/مدیر ساخته شده باشد | با حساب مدیر کلید بسازید |
| **«ماژول … فعال نیست»** | ماژولِ آن ابزار برای شما نصب/فعال نیست | از فروشگاه ماژول‌ها فعالش کنید |
| «ورودی نامعتبر است — …» | ایجنت پارامتر اشتباه فرستاده | معمولاً خودش اصلاح می‌کند؛ در غیر این‌صورت جمله را دقیق‌تر بنویسید (شناسه/تاریخ) |
| درخواستی که «شکست خورد» بعد از تأیید | قواعد خود اکسیر مانع شد (مثلاً نامه‌ی تکراری یا وقت دیگر آزاد نیست) | علت در جزئیات درخواست نوشته شده است |
| ایجنت ابزاری را نمی‌بیند | کلید به ماژول/ابزار دیگری محدود شده یا کلید فقط‌خواندنی است | دسترسی کلید را بررسی کنید |

سؤال دیگری دارید؟ از «پشتیبانی» داخل پنل تیکت بزنید.
